**schematize-copy** — copy que vende ao cliente; o briefing é insumo, nunca texto.

| Comando | O que faz |
|---|---|
| `/copy-help` | esta lista |
| `/copy-brief` | briefing -> tabela de tradução (fato interno -> percepção do cliente -> prova), antes de qualquer copy |
| `/copy-lp` | LP completa a partir do `/copy-brief`; roda o gate com `--briefing` |
| `/copy-variants` | 3 a 5 variações de headline, CTA ou anúncio, com ângulos diferentes |
| `/copy-review` | revisa copy existente: gate + leitura do que a máquina não lê; entrega reescrita |
| `/copy-load` | carrega à força TODO o corpo normativo e passa a aplicá-lo |
| `/copy-claude` | cria ou mescla o `CLAUDE.md` sempre-on de copy na raiz do repo |
| `/copy-cc` · `/copy-handoff` | context compact / handoff no archive |

Pareia com: `schematize-seo-writing` (artigo para ranquear), `schematize-design` (visual),
`schematize-institutional` (páginas legais e institucionais), `schematize-web` (implementação).
